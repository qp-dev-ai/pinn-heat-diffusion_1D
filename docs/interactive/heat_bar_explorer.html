Heat Bar Explorer

A metal bar, ends held at T = 0 (a perfect heat sink). Pick a starting temperature profile and a thermal diffusivity α, and watch how fast the bar cools back to zero.

∂T⁄∂t = α ∂²T⁄∂x²   |   T(0,t) = T(L,t) = 0   |   T(x,0) = sin(πx⁄L)

Units: x in m (bar length L = 1 m), α in m²⁄s, t in s. T is dimensionless (normalised so the initial peak is 1).

Both ends sit in an infinite T = 0 reservoir: heat continuously drains out at x = 0 and x = L, which is why the bar always cools toward zero. Larger α means the same drop happens faster. Any initial shape is decomposed into sine modes (Fourier series); each mode n decays as e−α(nπ⁄L)²t, so sharper shapes (like the square pulse) smooth out fastest.
